## 3. Design Planning

**Color theme**  
The site will use a premium dark theme inspired by modern developer portfolios. The main background will be deep charcoal, with contrasting accents of teal, coral, amber, and soft violet. This keeps the website eye-catching without making it feel like a single-color template.

**Fonts**  
The design will use a modern sans-serif font stack. Headings will be bold and spacious, while body text will stay readable and professional.

**Layout style**  
The layout will use a section-based landing page structure with:

- Sticky navigation
- Large hero section
- Stat cards
- Portfolio highlight strip
- Timeline layout for education and internship
- Gradient project showcase cards with hover effects
- Certification and skill grids
- Strong contact footer
- Smooth reveal animations for a polished portfolio feel

**Mobile responsiveness approach**  
The website will be built mobile-first using flexible grids, responsive spacing, fluid card layouts, and compact navigation behavior for smaller screens.

## 4. Technical Planning

**Technologies used**

- HTML5 for structure
- CSS3 for styling, layout, animations, and responsive design
- JavaScript for theme toggle, active navigation, and simple interactions

**Folder structure**

```text
portfolio/
  index.html
  styles.css
  script.js
  ROADMAP.md
```

**CSS methodology**  
CSS will follow a component-based structure with reusable classes for sections, cards, buttons, grids, tags, timelines, and utility layouts. CSS variables will be used for colors, spacing, shadows, and theme values.

**Responsive strategy**

- Use `grid-template-columns: repeat(auto-fit, minmax(...))` for card grids
- Use flexible units like `rem`, `%`, and `clamp()`
- Reduce hero layout to one column on mobile
- Keep buttons, cards, and contact links touch-friendly
- Test at desktop and mobile widths

## 6. Deployment Plan

**Hosting platform**  
The portfolio can be hosted on GitHub Pages, Netlify, or Vercel. For a beginner-friendly static portfolio, GitHub Pages is the recommended option.

**Domain planning**  
A custom domain is optional. A free GitHub Pages URL is enough initially. Later, a domain such as `ashrithathodishetty.dev` or `ashritha.dev` can be connected.

**Deployment steps**

1. Create a GitHub repository named `portfolio` or `ashrithathodishetty.github.io`.
2. Add `index.html`, `styles.css`, `script.js`, and project assets.
3. Commit and push the files to GitHub.
4. Open repository settings.
5. Go to Pages.
6. Select the main branch and root folder.
7. Save and wait for GitHub Pages to publish the site.
8. Test the live URL on desktop and mobile.
